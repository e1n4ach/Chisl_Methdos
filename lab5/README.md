# Лабораторная 5, вариант 8

Решается задача `u_t = a*u_xx + c*u`, `0 <= x <= pi/2`, `a > 0`, `c < 0`:
`u_x(0,t) = exp((c-a)*t)`, `u(pi/2,t) = exp((c-a)*t)`, `u(x,0) = sin(x)`.
Аналитическое решение: `U(x,t) = exp((c-a)*t)*sin(x)`.
Численные значения по умолчанию: `a=1`, `c=-1`, `T=1` (в задании конкретные a,c не указаны).

## Запуск

Python 3.10+, команды из корня проекта:

```bash
python -m pip install -r lab5/requirements.txt
python lab5/lab5.py --study
python lab5/checks.py
```

`--study` строит все сравнения и исследование устойчивости, сохраняет PNG и таблицу
`convergence.csv` в `lab5/plots`. Без этого флага рассчитывается выбранная комбинация.
`--show` дополнительно открывает окна графиков; `--output путь` меняет папку результатов.

```bash
python lab5/lab5.py --scheme explicit --bc three --n 40 --time 1 --sigma 0.4
python lab5/lab5.py --scheme implicit --bc first --n 80 --steps 2000
python lab5/lab5.py --scheme cn --bc pde --a 2 --c -0.5 --show
```

`--scheme`: `explicit`, `implicit`, `cn`; `--bc`: `first`, `three`, `pde`.
`--n` — число пространственных интервалов, `h=length/n`; `--time` — конечное время.
`--steps M` задаёт `tau=T/M`; иначе M округляется вверх из `sigma=a*tau/h²`.
Фактические шаги и sigma печатаются. При сгущении берутся N=10,20,40,80 и M=M0,4M0,16M0,64M0:
**фактическая sigma строго одинакова** для всех четырёх сеток, конечное время тоже одинаково.

В боковой панели выбираются схема, аппроксимация левого ГУ и параметры `a,c,n,T,σ`

слой; его фактическое время подписано под ползунком. На одном графике показаны

При неприменимости точного решения аналитическая кривая и оценка ошибки скрываются.
Изменение `a,c` при стандартных ГУ сохраняет применимость точной формулы.
Неустойчивая явная сетка выводит сообщение с предложением уменьшить `σ`.
Расчёт кешируется, поэтому движение ползунка не запускает численный метод повторно.
В раскрывающемся блоке доступно решение в пяти моментах (`solution.png`),
а основной график ошибки соответствует `error.png`.
Кнопка **«Провести исследование»** отдельно запускает существующие функции `lab5.py`:
сравнение девяти комбинаций на выбранных `a,c,n,T,σ` (`comparison.png`),
сгущение на сетках `n,2n,4n` при постоянной фактической σ (`error_vs_h.png`, `convergence.png`)
и устойчивость при выбранных `a,c,n,T`, σ около 0.4 и 0.6 (`stability.png`).
Последние два значения σ заданы функцией эксперимента для сравнения устойчивого и
неустойчивого режимов; схема и ГУ в исследованиях перебираются автоматически.
Рисунки создаются заново по параметрам, готовые файлы из `plots` не используются.
Результаты исследования сохраняются при движении ползунка и сбрасываются при изменении
настроек. Если отдельный эксперимент не удался (например, из-за неустойчивой явной
сетки или переполнения), интерфейс сообщает причину и показывает остальные результаты.
`app.py` использует функции из `lab5.py`; прежние команды запуска работают независимо.

## Формулы и настройки

Внутри области используется центральная разность второго порядка для `u_xx`.
Все схемы объединены формулой с весом theta: 0 — явная, 1 — неявная, 1/2 — Кранка — Николсона.
Для левого ГУ доступна общая форма `alpha*u_x + beta*u = left(t)`:

- `first`: `u_x ≈ (u1-u0)/h`, погрешность O(h).
- `three`: `u_x ≈ (-3*u0+4*u1-u2)/(2h)`, погрешность O(h²).
- `pde`: из `u1=u0+h*u_x+h²*u_xx/2+O(h³)` и `u_xx=(u_t-c*u-f)/a` получается
  `u_t(0) = 2a*(u1-u0)/h² + (c+2a*beta/(alpha*h))*u0 - 2a*left/(alpha*h) + f(0,t)`.
  Эта граничная строка интегрируется с тем же theta, что и внутренние строки.
  При theta=1 получается двухточечная формула методички; при theta=1/2 сохраняется
  второй порядок по времени. Общая точность при устойчивой сетке — O(tau+h²) для
  Эйлера и O(tau²+h²) для Кранка — Николсона со вторым порядком ГУ.

Правое ГУ подставляется непосредственно на каждом слое. Начальный слой `sin(x)`
задаётся точно **во всех узлах**, без замены крайних значений разностным ГУ при t=0.

Коэффициенты меняются аргументами `--a`, `--c`, `--length`, `--alpha`, `--beta`.
Функции ГУ имеют вид `amplitude*exp(rate*t)`:
`--left-amplitude`, `--right-amplitude`, `--left-rate`, `--right-rate`.
По умолчанию оба rate равны `c-a`. Для других функций редактируются методы
`Problem.initial`, `source`, `left`, `right`, `exact` и проверка `has_exact`.
При изменении ГУ программа проверяет применимость аналитического решения;
если оно неприменимо, отключает сравнение с U и графики ошибок.
Несовместимое с начальным условием правое ГУ при t=0 отклоняется.

Для исходной диссипативной задачи явная схема требует ограничения шага.
С учётом реакции достаточное внутреннее условие монотонности:
`2*sigma-c*tau <= 1`; привычное `sigma <= 1/2` относится к c=0.
Программа также вычисляет `rho(I+tau*L)` с учётом выбранного ГУ и отклоняет сетку
при rho>1. `--allow-unstable` разрешает намеренный эксперимент.
Спектральная проверка — диагностика на заданной сетке, не доказательство равномерной устойчивости;
при произвольных Robin-параметрах возможен физический рост, и критерий rho<=1 требует
отдельной интерпретации. Исследование `--study` сравнивает sigma около 0.4 и 0.6
для всех ГУ по росту малого высокочастотного возмущения.

## Функции и результаты

- `solve` — сетка и временные слои; возвращает `x, t, u`, где `u[k,i]`.
- `boundary_relation`, `spatial_operator` — формулы ГУ и три диагонали оператора.
- `factor_tridiagonal`, `solve_tridiagonal` — прогонка, факторизация выполняется один раз.
- `max_error` — `delta(t)=max_i|u_i-U_i|`, включая границы.
- `comparison_plots`, `convergence_study`, `stability_experiment` — исследования.

Графики: `solution.png` — численное и аналитическое решения в пяти моментах;
`error.png` — delta(t); `comparison.png` — все 9 сочетаний схем и ГУ;
`error_vs_h.png` — epsilon(h); `convergence.png` — ln(epsilon) от ln(h),
где epsilon=delta(T), наклон оценивается по трём самым мелким сеткам;
`stability.png` — устойчивость явной схемы.

При стандартном запуске для cn/pde, N=40: delta(T) ≈ 4.56e-5,
максимум delta(t) ≈ 8.84e-5. При сгущении наблюдаемые порядки всех комбинаций ≈ 1.98–2.02.
**Особенность варианта:** U_xx(0,t)=0, поэтому ведущий член ошибки первого ГУ
`h*U_xx/2` исчезает; наблюдаемый порядок около 2 не превращает эту формулу в формулу
второго порядка для общего случая. `checks.py` дополнительно проверяет решение
`exp(-t)*(sin(x)+cos(x))` с ненулевыми f и beta: там первое ГУ даёт порядок около 1,
остальные — около 2. Проверяются также прогонка, начальные/правые граничные значения,
алгебраические ГУ и отклонение неустойчивых сеток.
