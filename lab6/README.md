## Формулы

`h=1/N`, `τ=T/M`, `Dxx u_i=(u_(i−1)−2u_i+u_(i+1))/h²`.

- Крест: `u^(k+1)=2u^k−u^(k−1)+τ²(Dxx u^k−5u^k)`.
- Неявная: `(I−τ²L)u^(k+1)=2u^k−u^(k−1)`, `L=Dxx−5I` с выбранными ГУ.
  Правая часть PDE берётся на слое **k+1**, порядок по времени — первый.
- Первый слой: `v^1=v^0+τψ_h` или `v^1=v^0+τψ_h+τ²L_h v^0/2`.
  Taylor-формула выводится из PDE и использует тот же дискретный Lₕ, что и дальше.

Границы слева / справа (производная везде по положительному x):

| Способ | Слева | Справа |
|---|---|---|
| 2 точки, O(h) | `(u1−u0)/h−2u0=0` | `(uN−u_(N−1))/h−2uN=0` |
| 3 точки, O(h²) | `(-3u0+4u1−u2)/(2h)−2u0=0` | `(3uN−4u_(N−1)+u_(N−2))/(2h)−2uN=0` |
| 2 точки с PDE, O(h²) | `(u1−u0)/h−h(A0+5u0)/2−2u0=0` | `(uN−u_(N−1))/h+h(AN+5uN)/2−2uN=0` |

`A` — разностное ускорение; для PDE-границ оно интегрируется вместе с внутренними
строками. Для PDE-границы Taylor-старт применяется ко всем узлам без отдельного
замыкания слоя 1; его ускорение — `L_h φ` при t=0. Начальный слой задан по φ. Для трёхточечных ГУ
крайние значения сначала исключаются: остаётся трёхдиагональная система.
LU с выбором главного элемента подготавливается один раз на расчёт.

Полный вывод, обработка первого слоя, сверка DOC и результаты:
[METHODS.md](METHODS.md).

## Параметры и ограничения

`N` — число интервалов по x, `M` — число шагов времени, `T` — конечное время.
При вводе желаемого τ берётся `M=ceil(T/τ)`, фактический `τ=T/M` отображается.
Для креста проверяются спектр **с выбранными границами и членом −5u**,
`λmax<0` и `S=τ²max(−λ)/4<1`. Например, для первого ГУ при N=10 есть растущая
пространственная мода; нужно увеличить N. Неявная схема при отрицательном спектре
не требует S<1. Ограничения: `N≥3`, `M≥2`, `T>0`, до 12 млн значений сетки.

Интерфейс содержит графики u/U, ошибки по x и времени, таблицы с CSV, выбранные
сравнения и отдельную кнопку всех 12 комбинаций. Сравнение строится по текущим
N, M, T на трёх панелях по границам: до четырёх линий на каждой. Расчёты кешируются.
Исследования по h и τ — отдельные серии для всех 12 комбинаций, как в checks.py;
на сайте динамически строятся ошибки и измеренные порядки, доступны таблицы и CSV.
Готовые PNG интерфейс не читает. Результаты обоих исследований сохраняются независимо.
В исследовании h фиксируется M, в исследовании τ — N; дополнительный контроль
уменьшает фиксированный шаг вдвое. Порядки вычисляются по результатам.
По времени дополнительно строится разность с проверенным временным эталоном
на том же N: абсолютная ε(T) может выйти на пространственный предел точности.

Проверки успешно выполнены для всех 12 комбинаций и интерфейса Streamlit AppTest.
При N=40, M=200, T=1 и втором старте: ε(T)=0.008997 для креста/PDE,
0.025014 для креста/3 точки, 0.003347 для неявной/PDE.
Наблюдаемые порядки по h для креста со вторым стартом: 1.050 / 1.982 / 1.997.
При фиксированном N=60 порядки по τ для креста/PDE со вторым стартом:
2.073 / 2.066 / 2.025. Графики пересоздаются командой `python lab6/checks.py`.
