# Лабораторная работа 7 · Вариант 3

Решаем $u_{xx}+u_{yy}=0$ на $[0,1]\times[0,\pi/2]$ с условиями

$$
u(0,y)=\cos y,\quad u(1,y)=e\cos y,\qquad
u_y(x,0)=0,\quad u_y(x,\pi/2)=-e^x.
$$

В приложенном задании работа озаглавлена «Лабораторная работа 3».
Формулы варианта №3 совпадают с постановкой выше. Точное решение
$U=e^x\cos y$ удовлетворяет уравнению, поскольку $U_{xx}=U$ и $U_{yy}=-U$.
Подстановка $x=0,1$ даёт условия Дирихле. Из $U_y=-e^x\sin y$
следуют оба условия Неймана.

## Сетка и разностное уравнение

$N_x,N_y$ — числа интервалов. Сетка содержит $(N_x+1)(N_y+1)$ узлов
$x_i=i h_x$, $y_j=j h_y$, где $h_x=1/N_x$, $h_y=\pi/(2N_y)$.
В Python массив индексируется как `u[j, i]`. Обозначим $a=h_x^{-2}$,
$c=h_y^{-2}$. Сложение разложений Тейлора в узлах $x_i\pm h_x$
и вычитание $2u_{i,j}$ дают $h_x^2u_{xx}+O(h_x^4)$.
Так же получаем формулу для $u_{yy}$. Во внутренних узлах

$$
2(a+c)u_{i,j}-a(u_{i-1,j}+u_{i+1,j})-c(u_{i,j-1}+u_{i,j+1})=0.
$$

Эта аппроксимация $-\Delta u=0$ имеет погрешность $O(h_x^2+h_y^2)$.
Значения Дирихле задают вертикальные стороны и четыре угла. Их вклад
в соседних строках переносится в правую часть с коэффициентом $a$.
Условия Неймана накладываются на горизонтальных сторонах при $0<i<N_x$.

### Три точки с одной стороны

Обозначим $g_0=0$, $g_1=-e^{x_i}$, $h=h_y$ и опустим индекс $i$.
По формуле Тейлора комбинация $-3u_0+4u_1-u_2$ даёт $2h u_y(0)+O(h^3)$,
поскольку члены с $u_{yy}$ сокращаются. Верхняя формула получается
отражением и сменой знака производной. Отсюда

$$
u_0=\frac{4u_1-u_2-2hg_0}{3},\qquad
u_{N_y}=\frac{4u_{N_y-1}-u_{N_y-2}+2hg_1}{3}.
$$

Эти значения исключаются из системы. Например, нижняя соседняя строка
при $j=1$ получает вид

$$
(2a+2c/3)u_{i,1}-a(u_{i-1,1}+u_{i+1,1})
 -(2c/3)u_{i,2}=-2g_0/(3h).
$$

В верхней соседней строке справа стоит $2g_1/(3h)$. После каждого
прохода формулы восстанавливают значения на горизонтальных сторонах.

### Центральная формула с фиктивными узлами

Разность $u(h)-u(-h)=2h u_y(0)+O(h^3)$ даёт второй порядок
для граничной производной. Снизу $u_{-1}=u_1-2hg_0$, сверху
$u_{N_y+1}=u_{N_y-1}+2hg_1$. Подстановка в уравнение на
горизонтальной стороне, где $D_{xx}$ — центральная разность по $x$, даёт

$$
\begin{aligned}
-D_{xx}u_{i,0}+2c(u_{i,0}-u_{i,1})&=-2g_0/h,\\
-D_{xx}u_{i,N_y}+2c(u_{i,N_y}-u_{i,N_y-1})&=2g_1/h.
\end{aligned}
$$

Крайние горизонтальные ряды входят в вектор неизвестных. После умножения
на $h/2$ эти строки задают одностороннюю производную с поправкой
на $D_{xx}u$ из уравнения. В такой нормировке невязка точного $U$
имеет порядок $O(h_y^2+h_y h_x^2)$. В исходной нормировке строки Лапласа
погрешность на границе может быть $O(h_y+h_x^2)$.
Глобальный второй порядок проверяется сгущением сетки.

## Итерации и критерий остановки

После подстановки условий получаем $Av=b$, где $A=D+L+R$, $D$ —
диагональ, $L$ и $R$ — строгие нижняя и верхняя части. Неизвестные
перебираются сначала по $x$, затем по $y$. Начальное приближение $v^0=0$.
Для невязки $r^k=b-Av^k$ обновления имеют вид

$$
\begin{aligned}
\text{Либман (Якоби)}\qquad v^{k+1}&=v^k+D^{-1}r^k,\\
\text{Зейдель}\qquad v^{k+1}&=v^k+(D+L)^{-1}r^k,\\
\text{SOR}\qquad v^{k+1}&=v^k+(D+\omega L)^{-1}\omega r^k,\quad 1\le\omega<2.
\end{aligned}
$$

Якоби использует значения предыдущего прохода. Зейдель использует уже
обновлённые компоненты при проходе по строкам. SOR умножает поправку
Зейделя в текущей строке на $\omega$, используя уже релаксированные
компоненты в предыдущих строках. Значение $\omega=1$ даёт Зейделя.
Обратные матрицы в формулах обозначают решение диагональной
или нижнетреугольной системы. Для обеих схем матрица $A$ диагонально
преобладает, строгие строки есть рядом с условиями Дирихле, граф
ненулевых связей связен. Умножение первого и последнего активных
горизонтальных рядов на $3/2$ в трёхточечной схеме (при $N_y>3$)
или $1/2$ в схеме с фиктивными узлами симметризует систему.
Эти свойства обеспечивают сходимость Якоби, Зейделя и SOR при указанных $\omega$.

На каждом шаге, включая $k=0$, записываются $\|r^k\|_\infty$ и
$E_k=\max_{i,j}|u^k_{i,j}-U(x_i,y_j)|$. Расчёт останавливается при
$\|r^k\|_\infty\le\varepsilon$, достижении `max_iter` или появлении
нечисловых либо бесконечных значений. Интерфейс и CSV показывают статус.
Точное решение используется для измерения ошибки.

Из дискретного принципа максимума следует оценка вклада итераций.
Функция $w=x(1-x)/2$ удовлетворяет $Aw=\mathbf{1}$ на неизвестных
и равна нулю на вертикальных сторонах. Поэтому отклонение от точного
решения системы ограничено $\|r^k\|_\infty/8$ на неизвестных. Для
трёхточечной схемы при восстановлении края применяется множитель $5/3$
из коэффициентов $(4/3,-1/3)$.

## Графики и исследование

- `surfaces.png` показывает численное и точное решения на одной сетке.
  `error_map.png` показывает $|u-U|$, а линии отмечают выбранные сечения.
- `sections.png` сравнивает $u,U$ и ошибку при фиксированных $x$ и $y$ через
  выбранные узлы. Сечения и вся сетка доступны в CSV.
- `history.png` содержит $E_k$ и $\|r^k\|_\infty$ по итерациям.
  Горизонтальная линия показывает порог $\varepsilon$.
- `comparison.png` совмещает истории трёх методов, `iterations.png`
  показывает число проходов, `comparison_errors.png` — карты ошибок
  в общей цветовой шкале. Сетка, границы, старт, $\varepsilon$ и `max_iter`
  одинаковы. При остановке по лимиту число итераций показывает затраченные проходы.
- `convergence_hx.png` и `convergence_hy.png` показывают сгущение по одной
  оси. Ошибка $E$ относительно $U$ включает вклад фиксированного шага.
  Для оценки порядка по изменяемому шагу вычисляется $E_{\mathrm{ref}}$
  относительно сеточного решения с тем же фиксированным шагом и с шагом
  по изучаемой оси в 16 раз меньше, чем на последней сетке серии.
  Сеточные эталоны вычисляются прямым разреженным решателем.
  Разность с контрольным эталоном в 8 раз мельче последней сетки
  записывается в CSV. Сравнения выполняются в совпадающих узлах.
- `convergence_both.png` показывает сгущение обеих осей в одной пропорции
  и ошибку к $U$. Для абсциссы используется $h_x$.

В каждой серии порядок вычисляется по соседним сеткам

$$
p=\frac{\log(E_{\mathrm{coarse}}/E_{\mathrm{fine}})}
        {\log(h_{\mathrm{coarse}}/h_{\mathrm{fine}})}.
$$

В столбце `p` используется ошибка к $U$, в `p_ref` — к сеточному эталону.
Первая строка серии и пары с недостигнутым порогом либо нулевой ошибкой
имеют пустое значение порядка. На логарифмических графиках нулевые
значения пропускаются, в таблицах сохраняются исходные числа.

## Запуск

Команды выполняются из корня проекта. Требуется Python 3.10 или новее.
В Windows можно использовать `py` вместо `python`.

```bash
python -m pip install -r lab7/requirements.txt
python -m streamlit run lab7/app.py --server.address 127.0.0.1
```

Откройте [Streamlit](http://127.0.0.1:8501). Слева задайте метод, аппроксимацию
Неймана, размеры сетки и параметры итераций. Кнопка **«Рассчитать»**
применяет параметры. Вкладки сравнения и сгущения запускают свои расчёты
по кнопкам. Ползунки сечений используют уже рассчитанное поле. Для каждой
таблицы есть загрузка CSV. Кнопка **«Сохранить PNG и CSV»** записывает
текущий комплект файлов в `lab7/results/ui/`.

### Повторное построение из командной строки

```bash
python -m lab7.cli --compare --study all
python -m lab7.cli --boundary ghost --method sor --omega 1.85 --compare --study all --output lab7/results/ghost
python -m lab7.cli --method seidel --nx 32 --ny 48 --epsilon 1e-9 --max-iter 30000 --section-i 8 --section-j 24
python -m lab7.cli --study hy --base 8 --fixed 32 --levels 3
```

`--method` принимает `jacobi`, `seidel`, `sor`. `--boundary` принимает
`three` и `ghost`. `--study` принимает `hx`, `hy`, `both` и `all`.
`--fixed` задаёт число интервалов по фиксированной оси. Для `both`
это начальное $N_y$, а `--base` задаёт начальное $N_x$. Без `--output`
файлы пишутся в `lab7/results/` с заменой одноимённых файлов.
CSV сохраняется в UTF-8 с BOM. `summary.csv` содержит параметры и итог,
`boundaries.csv` — максимальные невязки на четырёх сторонах. Для
фиктивных узлов производная проверяется через их восстановление из
уравнения Лапласа на горизонтальной границе.

## Структура и проверки

`problem.py` задаёт данные варианта, `boundaries.py` собирает систему,
`solver.py` выполняет итерации, `analysis.py` формирует таблицы исследований.
`plots.py` и `export.py` используются как в `app.py`, так и в `cli.py`.

```bash
python -m unittest -v lab7.checks lab7.ui_checks
```

Проверяются аналитическое решение, разностные уравнения и границы,
три итерационных метода на нескольких прямоугольных сетках, предел
итераций, порядки при трёх способах сгущения, работа элементов интерфейса
и сохранение PNG/CSV. При $N_x=24$, $N_y=32$, $\varepsilon=10^{-8}$ для
трёхточечной схемы Якоби, Зейдель и SOR ($\omega=1.8$) сошлись за
4133, 2064 и 185 итераций. На последней паре совместного сгущения
$12\times16\to24\times32$ измеренный порядок равен 2.015 для
трёхточечной схемы и 1.985 для схемы с фиктивными узлами.
